# รัฐบานประชาชน

ต้นแบบเว็บไซต์แพลตฟอร์มข้อมูลสาธารณะภาษาไทยที่ช่วยให้ประชาชนเข้าถึงบริการ นโยบาย และช่องทางการมีส่วนร่วมได้ง่ายขึ้น

## สิ่งที่เพิ่มในต้นแบบนี้

- หน้าแรกแบบ responsive รองรับมือถือ แท็บเล็ต และเดสก์ท็อป
- โครงสร้าง semantic HTML พร้อม skip link และสถานะสำหรับ screen reader
- ส่วนบริการประชาชน นโยบาย ความคืบหน้า และการมีส่วนร่วม
- หน้า **กรอบนโยบาย** ว่าด้วยความเสมอภาค กฎหมายที่เป็นธรรม รายได้ สวัสดิการ และราชการคุณธรรม
- เมนูมือถือและโหมดความคมชัดสูงโดยไม่ต้องใช้ framework
- ฟอร์มสาธิตการแสดงความคิดเห็นพร้อมข้อความตอบกลับ
- สีและตัวอักษรที่ออกแบบให้เหมาะกับการอ่านภาษาไทย
- meta description และโครงสร้างที่พร้อมต่อยอด SEO

## เริ่มใช้งาน

เปิด `index.html` ในเบราว์เซอร์ได้ทันที หรือใช้ static server เช่น:

```bash
python3 -m http.server 8000
```

จากนั้นเปิด <http://localhost:8000>

> ข้อมูลสถิติ นโยบาย และรายการบริการในเวอร์ชันนี้เป็นข้อมูลจำลองเพื่อการออกแบบและสาธิตเท่านั้น ยังไม่ได้เชื่อมต่อกับหน่วยงานหรือฐานข้อมูลจริง

## แนวทางต่อยอดก่อนใช้งานจริง

1. เปลี่ยนข้อเสนอเป็นนโยบายที่มีเจ้าภาพ งบประมาณ กรอบเวลา และตัวชี้วัดที่ตรวจสอบได้
2. เชื่อมต่อ API ที่ตรวจสอบแหล่งที่มาได้ พร้อมวันที่ปรับปรุงและประวัติการแก้ไข
3. เพิ่มระบบค้นหา ตัวกรอง และหน้ารายละเอียดนโยบาย
4. เพิ่ม backend สำหรับรับเรื่องและติดตามสถานะ โดยออกแบบเรื่องความปลอดภัยและ PDPA ตั้งแต่ต้น
5. รับฟังความคิดเห็นจากกลุ่มผู้ใช้งานที่หลากหลายและนำผลไปปรับปรุงนโยบาย
6. ทดสอบด้วย Lighthouse, axe และผู้ใช้ที่ใช้ assistive technology
7. เพิ่มการทดสอบอัตโนมัติและ CI สำหรับ HTML, accessibility และลิงก์เสีย
8. จัดทำ privacy notice, terms of use และช่องทางติดต่อผู้ดูแลเว็บไซต์ให้ชัดเจน
