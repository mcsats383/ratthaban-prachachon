# รัฐบานประชาชน

ต้นแบบเว็บไซต์แพลตฟอร์มข้อมูลสาธารณะภาษาไทยที่ช่วยให้ประชาชนเข้าถึงบริการ นโยบาย และช่องทางการมีส่วนร่วมได้ง่ายขึ้น

> **สถานะโครงการ:** ต้นแบบสำหรับการออกแบบและสาธิต ยังไม่ได้เชื่อมต่อกับหน่วยงานหรือฐานข้อมูลจริง

## ภาพรวม

รัฐบานประชาชนออกแบบโดยยึดประชาชนเป็นศูนย์กลาง เน้นข้อมูลที่เข้าใจง่าย การเข้าถึงสำหรับทุกคน และการตรวจสอบได้ เว็บไซต์ใช้ HTML, CSS และ JavaScript แบบไม่พึ่งพา framework จึงสามารถเปิดดูและนำไปต่อยอดได้ง่าย

## ความสามารถในปัจจุบัน

- หน้าแรกแบบ responsive รองรับมือถือ แท็บเล็ต และเดสก์ท็อป
- โครงสร้าง semantic HTML พร้อม skip link และสถานะสำหรับ screen reader
- ส่วนบริการประชาชน นโยบาย ความคืบหน้า และการมีส่วนร่วม
- หน้า **กรอบนโยบาย** ว่าด้วยความเสมอภาค กฎหมายที่เป็นธรรม รายได้ สวัสดิการ และราชการคุณธรรม
- เมนูมือถือและโหมดความคมชัดสูงโดยไม่ใช้ framework
- แบบฟอร์มสาธิตการแสดงความคิดเห็นพร้อมข้อความตอบกลับ
- หน้าแจ้งเบาะแสและร้องเรียน พร้อมบันทึกแบบร่างไว้ในเบราว์��ซอร์
- ส่งออกข้อมูลแบบร่างเป็นไฟล์ JSON และล้างข้อมูลในเครื่องได้
- สีและตัวอักษรที่ออกแบบให้เหมาะกับการอ่านภาษาไทย
- meta description และโครงสร้าง HTML ที่พร้อมต่อยอด SEO

## โครงสร้างไฟล์

| ไฟล์ | รายละเอียด |
| --- | --- |
| `index.html` | หน้าแรกและเนื้อหาหลักของโครงการ |
| `policies.html` | กรอบนโยบายและแนวทางติดตามผล |
| `report.html` | แบบฟอร์มแจ้งเบาะแสและร้องเรียนสำหรับการสาธิต |
| `styles.css` | รูปแบบ สี การจัดวาง และ responsive design |
| `app.js` | เมนู โหมดความคมชัดสูง แบบฟอร์ม และ local storage |
| `DEVELOPER-TH.md` | คู่มือการสื่อสารไทย–อังกฤษสำหรับผู้พัฒนา |

## เริ่มใช้งาน

เปิด `index.html` ในเบราว์เซอร์ได้ทันที หรือใช้ static server เช่น:

```bash
python3 -m http.server 8000
```

จากนั้นเปิด <http://localhost:8000>

## การพัฒนา

ก่อนส่งการเปลี่ยนแปลง ให้ตรวจสอบอย่างน้อยดังนี้:

1. เปิดทุกหน้าในเบราว์เซอร์และทดสอบบนหน้าจอขนาดเล็ก
2. ตรวจสอบเมนูมือถือและโหมดความคมชัดสูง
3. ทดสอบการใช้งานด้วยแป้นพิมพ์โดยไม่ใช้เมาส์
4. ตรวจสอบข้อความภาษาไทย การเข้ารหัส UTF-8 และลิงก์ภายใน
5. ตรวจสอบสถานะ `role="status"`, label ของฟอร์ม และลำดับหัวข้อ
6. อย่าใส่ข้อมูลส่วนบุคคลจริงในแบบฟอร์มต้นแบบ

ดูแนวทางการสื่อสารและคำศัพท์ร่วมกันได้ที่ [DEVELOPER-TH.md](DEVELOPER-TH.md)

## ข้อมูลและความเป็นส่วนตัว

ข้อมูลสถิติ นโยบาย รายการบริการ และความคืบหน้าในเวอร์ชันนี้เป็นข้อมูลจำลองเพื่อการออกแบบและสาธิตเท่านั้น แบบฟอร์มแจ้งเบาะแสเก็บข้อมูลไว้ใน `localStorage` ของเบราว์เซอร์บนอุปกรณ์ของผู้ใช้ และยังไม่ได้ส่งให้หน่วยงานจริง

อย่าใส่ข้อมูลลับ ข้อมูลสุขภาพ ข้อมูลทางการเงิน หรือข้อมูลส่วนบุคคลที่ละเอียดอ่อนในต้นแบบนี้ การนำไปใช้งานจริงต้องมี backend ที่ปลอดภัย นโยบายความเป็นส่วนตัว ระยะเวลาเก็บรักษาข้อมูล การควบคุมสิทธิ์ และกระบวนการรับเรื่องที่ชัดเจน

## แนวทางต่อยอดก่อนใช้งานจริง

1. เปลี่ยนข้อเสนอเป็นนโยบายที่มีเจ้าภาพ งบประมาณ กรอบเวลา และตัวชี้วัดที่ตรวจสอบได้
2. เชื่อมต่อ API ที่ตรวจสอบแหล่งที่มาได้ พร้อมวันที่ปรับปรุงและประวัติการแก้ไข
3. เพิ่มระบบค้นหา ตัวกรอง และหน้ารายละเอียดนโยบาย
4. เพิ่ม backend สำหรับรับเรื่องและติดตามสถานะ โดยออกแบบความปลอดภัยและการคุ้มครองข้อมูลส่วนบุคคลตั้งแต่ต้น
5. เพิ่มระบบยืนยันตัวตน การควบคุมสิทธิ์ การตรวจสอบกิจกรรม และการป้องกัน spam
6. รับฟังความคิดเห็นจากกลุ่มผู้ใช้งานที่หลากหลายและนำผลไปปรับปรุงนโยบาย
7. ทดสอบด้วย Lighthouse, axe และผู้ใช้ที่ใช้ assistive technology
8. เพิ่มการทดสอบอัตโนมัติและ CI สำหรับ HTML, accessibility และลิงก์เสีย
9. จัดทำ privacy notice, terms of use และช่องทางติดต่อผู้ดูแลเว็บไซต์ให้ชัดเจน
10. ตรวจสอบเนื้อหาและข้อมูลกับหน่วยงานเจ้าของเรื่องก่อนเผยแพร่จริง

## ใบอนุญาตและการนำไปใช้

โปรดเพิ่มใบอนุญาตที่เหมาะสมก่อนเปิดให้ผู้อื่นนำโค้ดไปใช้ต่ออย่างเป็นทางการ และตรวจสอบใบอนุญาตของฟอนต์ ไลบรารี หรือบริการภายนอกที่นำมาใช้ทุกครั้ง
